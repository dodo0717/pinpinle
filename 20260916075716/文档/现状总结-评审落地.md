## 三、当前生效的规则

| 模块 | 规则 |
|---|---|
| 判星 | 按本局拼好几张 + 逐关三条星线（星线未改） |
| 排行分 | 每拼好一张 100 分 + 速度分：距上一张 0 秒 +60，每慢 1 秒 −10，6 秒起 +0 |
| 总榜 | 各关有效成绩最高分之和，困难 ×1.5；同分按累计星数 |
| 关卡榜 | 本关本模式 3★ 且不续命的最高分 |
| 我的成绩 | 我的排名 / 总积分（关卡榜为本关最高分）/ 累计星数 ⭐n/360 |
| 续命 | 每局一次，+60 秒，最高 2★，不计排行；有续命券先用券 |
| 时长 | 逐关表，见 `核心/config.ts` `LEVEL_TIME` / `NIGHTMARE_LEVEL_TIME` |
| 体力 | 上限 10（第 50 关宝箱 +2）、15 分钟回 1 颗、广告每次 +2（每天 5 次）、首次 3★ 返还 1 颗 |
| 困难模式 | 同关简单模式通关（≥1★）即开 |
| 图鉴 | 每 10 颗星解锁一张普通卡；困难每拿一个 3★ 升一张金卡（最多 36） |
| 章节宝箱 | 简单通关第 40 / 45 / 50 / 55 / 60 关：头像框 / 糖果皮肤 / 称号 + 体力上限 +2 / 果冻皮肤 / 头像框 |
| 签到 | 7 天一轮、断签不清零：体力 2 / 2 / 续命券 / 体力 3 / 3 / 续命券 / 金卡 + 体力 3 |
| 每日挑战 | 每天一关（第 4~30 关按日期轮换），所有人同一盘，不耗体力，每天 3 次，当天首次通关 +2 体力，日榜只留当天最好 |
| 回流 | 3 天没来：补满体力 + 续命券 1 张 |
| 邀请 | 注册 24 小时内的新玩家打开分享卡：双方各 +3 体力；同一人只算一次，邀请人每天上限 10 |
| 主题 | 第 2 关糖果嘉年华 / 第 3 关果冻乐园 / 第 4 关贴纸手账，其余原样式 |
