## 3. 关键口径（改任何东西前先确认这几条）

1. **星线以《关卡配置表》为准**（`src/core/config.ts` 的 `LEVEL_STAR_LINES`，第 1~60 关逐关给定）。改星线要**表 + 代码两处同步**，`npm test` 会校验，只改一处直接报错。
2. **噩梦模式与普通同分**（`NIGHTMARE_STAR_LINES` 是副本，现在不动）。差别只在交换规则：普通整片任意距离，噩梦整片一次一格（每分约 7~9 次交换 vs 普通约 3 次）。
3. **不设暂停按钮**（防截图作弊），退出后倒计时继续走；切后台可断点恢复，但离开期间时间照扣。
4. **难度杠杆是 `ma`（同动物出几个情绪）而非棋盘大小**：3×4 / 4×4 / 5×4 在普通模式下每分交换次数几乎一样（3.03 / 2.92 / 2.95）。`ma` 与网格均已顶格（6 与 5×4），只剩星线还能加。
5. **图片编号 0~10 锁死**（`src/core/ledger.ts` 的 `ANIMAL_IMAGE_IDS` 是唯一权威来源），改编号只改那一处再跑 `npm test` + `npm run calibrate`。
6. **置灰按钮仍可点**（`opacity:.42` + toast 说明原因），不用真 `disabled`。
