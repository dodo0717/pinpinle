# 关卡地图 AI 出图提示词（豆包 / 即梦 / MJ 通用）

> 工作流：**母版蓝图 → 分屏生成（带重叠接口）→ 裁切 → 边界验收**
> 三张地图 × 三屏 = 9 张正式图。复制下面的提示词即可，{} 里的变量查文末表格。

---

## 0. 尺寸与方向（先看这个，别搞反）

- 正式每屏：**1080 × 1920**（9:16）
- AI 每次出：**1080 × 2300**（竖版）
  - **画面下方 1920 = 正式内容**
  - **画面上方 380 = 接口延伸区**（给下一屏接图用，最后会被裁掉）
- ⚠️ **方向是反的**：本游戏地图**从下往上推进** —— 最底部是旅程起点（第 1 关），越往上越深入，最顶部是终点。
  所以生成顺序是 **底屏 → 中屏 → 顶屏**，每屏取上一张的**顶部 380px** 当接口。
- 每屏上方的 380px **仍然是地形**（路还在往远处延伸），**不要**画成天空/画面尽头/地平线终点。

---

## 1. Step 0：先出「地图蓝图」（1 张，三张地图各一张）

> 不是成品，只是把地形走势定死，后面三屏都拿它当参考图。

```
竖版游戏关卡地图的俯视结构蓝图，1080 × 1920。
2.5D 俯视视角，简洁线稿+色块风格，像游戏设计文档里的关卡布局图。

这是一条纵向连续的山道地图，从画面底部（起点）蜿蜒向上到画面顶部（终点）。
内容要求：
- 一条 S 形蜿蜒主道，从底部入口开始，左右摆动向上延伸
- 沿途分布 {节点数} 个圆形关卡平台，间隔均匀，用圆圈表示
- 标出：河流/木桥、石阶、坡地、森林带、开阔草地、大型地标（城堡/大树屋/风车等）
- 底部是旅程起点（村庄/入口门/山脚），顶部是终点（{终点地标}）
- 主题：{世界主题}

构图：上下贯通，道路不要断。
不要：任何文字、数字、UI、边框、角色特写。
风格：扁平色块示意图，配色清淡。
```

## 2. 通用前缀（三屏每一张都要带，整段复制）

```
3D 卡通糖果风格游戏关卡地图，明亮饱和，像《糖果传奇》《Cookie Jam》那类休闲消除游戏的场景。
镜头：2.5D 俯视，略带透视，能看到地面也能看到一点物体侧面。
光照：统一从左上 45° 打光，柔和阴影，晴天（{时段}），全局一致。
材质：奶油感/糖霜感，圆润造型，高饱和暖色调，无写实纹理，无噪点。

【硬性要求 —— 连续世界】
1. 这是一整条连续的纵向世界，不是独立的一张画。
   This is one continuous vertical world, not an independent image.
2. 画面上方 380px 是接口区：地形、道路、河流、植被必须自然继续向上延伸，
   不得出现画面终点、边框、横向切线、天空收尾。
   The top edge must continue upward naturally; no ending, no frame, no artificial edge.
3. 道路/河流/石坡/植被带在接缝处必须几何连续（同样的位置、宽度、走向）。
   Roads, rivers, cliffs and terrain must remain geometrically continuous across the seam.
4. 光照方向、阴影方向、时间、大气氛围与上一张完全一致。
   Maintain identical lighting direction, shadow direction and atmosphere.
5. 地形材质、纹理密度、植被风格、环境配色与上一张完全一致。
   Maintain identical materials, vegetation style and color language.
6. 禁止在画面上方 380px 出现：新的地图起点、场景切换、边框、装饰性收边。
   No new starting point, no scene transition, no framing at the top.

【必须保留的几何 —— 以我给的灰模底图为准】
- 灰模底图上的白色圆圈 = 关卡平台，位置一一对应，不可挪动、不可增减
- 每个平台画成一个圆形糖果石台/圆盘，直径约 190（比白圈略大一圈），表面平整
- 平台周围 ±110px 内保持干净：不要放大树、岩石、云、建筑压住它
- 白圈之间的白色虚线 = 小径，画成蜿蜒的糖果小路，路面宽约 34，材质与地形协调

【绝对不要画】
- 任何文字、数字、字母、水印
- 关卡编号、星星、锁头、分数、进度条（这些是程序运行时另外画上去的）
- UI 面板、按钮、边框、箭头指示
```

## 7. 裁切规则（三张出完后统一做）

每张 1080 × 2300 的成品：

```
裁掉「顶部 380px」，保留下方 1080 × 1920
```

| 图 | 保留下来的部分 | 在整条 5760 地图里的位置 |
|---|---|---|
| 第1屏（底） | 下方 1920 | y 3840 ~ 5760（地图最底部） |

| 第3屏（顶） | 下方 1920 | y 0 ~ 1920（地图最顶部） |

## 8. 验收清单（每张图过一遍）

- [ ] 尺寸 1080 × 2300，竖版，无变形
- [ ] 画面上方 380px 是地形延伸，没有"画到头"的感觉，没有边框/横向切线
- [ ] 灰模底图上的白圈**一个不多一个不少**，位置对得上（底 6 / 中 8 / 顶 6）
- [ ] 每个平台周围 ±110px 干净，没有树/石头/云压住
- [ ] 小路连着所有平台，走向与灰模一致
- [ ] 接缝坐标对得上（见上表），两侧道路宽度、倾角、材质一致
- [ ] 没有任何文字、数字、星星、锁头、UI
- [ ] 光源方向（左上 45°）、阴影、时段与前一张一致
- [ ] 第 2、3 屏的底部 380px 与上一张的顶部 380px 是同一片地形

## 9. 给豆包的操作顺序（照着做就行）

```
① 出蓝图（第1节提示词 + 主题变量）           → 存为 世界N-蓝图.png
② 出底屏（通用前缀 + 第3节 + 灰模底图PNG）    → 1080×2300
③ 出中屏（通用前缀 + 第4节 + 灰模底图 + 底屏成品）→ 1080×2300
④ 出顶屏（通用前缀 + 第5节 + 灰模底图 + 中屏成品）→ 1080×2300
⑤ 三张各裁掉顶部 380 → 得到 3 张 1080×1920
⑥ 拼起来看接缝，不齐就重出中屏（只重出中屏即可）
⑦ 换下一个世界，回到 ①
```

> 灰模底图 PNG 在 `map-slices/` 目录下，文件名是「世界N-主题_段X位置_Lx-Ly.png」，
> 出哪一屏就上传对应那张 —— 它就是白圈 + 虚线的结构图，只参考几何，不参考画风。
