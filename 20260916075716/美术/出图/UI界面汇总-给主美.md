# UI 界面汇总（给主美重设计用）

> 用途：把当前灰盒原型里**所有可显示、可点击的界面**完整列出来，供主美重设计视觉稿。
> 口径：本文只描述**现状事实**（界面结构、元素、文案、状态、尺寸、动效），不描述玩法规则细节。
> 代码出处：`web/index.html`（棋盘与 HUD 骨架）、`web/ui.css`（元系统界面样式）、`web/ui/*.ts`（各界面构建）、`web/ui/text.ts`（全部玩家文案）。
> 灰盒观感截图：`shots/m9/`（含荣誉弹窗三档、排行榜、图鉴、设置等）、`shots/m7/`（动效与棋盘）、`shots/*.png`（真机尺寸对比）。
> 版本：已按最新策划口径修订（见 §0）。

## 0. 最新规则口径（重设计前先看这 4 条）

| # | 规则 | 对设计的影响 |
|---|---|---|
| 1 | **不设暂停按钮**（防截图作弊 —— 有暂停就能截图后离线慢慢想） | 玩法屏**不出现任何暂停入口**，也没有暂停弹窗。故意为之，**不是待补的缺口**，请勿新增 |
| 2 | **退出游戏后倒计时继续走** | 退出同样不能变相"暂停"。两种退出要分清：①点「← 主界面」= 主动放弃本局（退体力、断点作废）；②切后台 / 直接关掉 = 可恢复（弹「断点恢复」窗），但**离开期间的时间照扣**。相关文案要按"时间照走"表述。**离开太久、时间已扣光 → 下次启动直接出本关判定结果**（不弹恢复窗），并且**不发续命机会** —— 玩家不在场，续命那 60 秒补不回他离开的时间。**离线只让时间继续走，分数照算**：够 3★ 就是 3★、该上百强榜就上榜，不因离线降档 |
| 3 | **道具系统尚未设计，道具按钮待定** | 玩法屏暂时**不画道具位**；日后上道具需另行出稿 |
| 4 | **图鉴奖励并入"任务功能"** | 图鉴页**不带奖励领取出入口**；奖励相关界面属于后续的任务功能，当前**未开发、暂不出稿** |

> 补充说明（避免误判为漏洞）：
> - 进关后**还没点过棋盘**的一局，计时尚未启动，退出不扣时间；
> - **看广告播放期间**与**消除动画播放期间**的停表是正常表现，不属于"暂停入口"，不必按漏洞处理。

## 1. 全局规格（重设计前必须知道的硬约束）

| 项 | 规格 | 说明 |
|---|---|---|
| 设计画布 | **1080 × 1920**（9:16 竖屏） | 所有字号/间距按这个尺寸写，整体等比缩放适配真机，**不要按 CSS 小字号思考** |
| 安全边 | 左右各 **28 屏幕 px**、上下各 **12 屏幕 px** | 这段是**系统手势区**（安卓侧边返回 / iOS 侧滑返回），画布不贴屏幕边；重要内容与可拖拽区不要压到这里 |
| 缩放方式 | `transform: scale()` 等比缩放 + 居中，画布高度自适应视口 | 390×844 真机实测：画布 334×820 |
| 字体 | `-apple-system / PingFang SC / Microsoft YaHei`（系统字体栈，无自定义字库） | 若引入字库需走小程序包体预算 |
| 全局禁交互 | 页面**禁用文本选中 / 长按菜单 / 浏览器手势**（`user-select:none`、`touch-action:none`、`overscroll-behavior:none`） | 只有报错条 `#errbar` 可选中文字 |
| 触摸反馈 | 所有按钮按下统一 `transform: scale(.94 ~ .97)` | 无长按、无 hover 态（移动端不需要） |
| **置灰按钮仍然可点** | 置灰 = `opacity:.42`，点击后 **toast 说明原因**，**不使用真 `disabled`** | 这是全局交互铁律，视觉上必须保留"可点但不满足条件"的表达。例外：开发工具条探测期用真 `disabled`（`.45` 灰） |
| 色板（当前灰盒） | `--cream #fff7ec` / `--cream-2 #fdeed8` / `--card #fffdf8` / `--honey #e0a94a` / `--honey-soft #f6d9a0` / `--ink #4a3b2a` / `--ink-soft #9c8768` | 背景是奶油色径向渐变（`radial-gradient(120% 80% at 50% 0%, #fffdf6 → #fff7ec → #fdeed8)`），所有屏幕共用 |
| 屏幕容器 | 每屏 `<section class="screen">`，同时只显示一个（`position:absolute;inset:0;flex-column`） | 共 **6 个屏** |
| 层叠顺序 | 屏 → 弹窗 `z=90` → toast `z=120` → 引导气泡 `z=150` → 报错条 `z=999` | 弹窗遮罩 `rgba(74,59,42,.42)` |

## 4. 弹窗族（7 种在用 + 1 类已被取代，共用一套骨架）

### 4.1 通用骨架（`ui/dialog.ts`）

固定顺序：**荣誉图/星 → 标题 h2 → 副文案 → 大号分数 → 辅助文案 → 多行正文 → 按钮区（每行 1~2 个）**

- 卡片：宽 720、圆角 48、内边距 56×48、居中；遮罩深棕 42%
- 按钮 `.dialog-btn`：描边胶囊；`.primary` = 蜜色实底；`.dim` = 42% 灰（**仍可点**，点了 toast 原因）
- 按下统一触感反馈（震动）

### 4.2 弹窗清单

| 弹窗 | 触发 | 头部 | 标题 / 正文 | 按钮（按行） |

## 9. 给主美的交付建议（按优先级）

1. **先定主界面 + 玩法屏 + 荣誉弹窗**：这三块承担 90% 的游戏时长与"第一眼品质"。
2. **荣誉弹窗三档需成套**：超神/王者/优秀只换配色不够，建议出各自的图标 + 光环/粒子 + 底座（当前是 CSS 占位）。
3. **图标表**：按 §8 的 emoji 清单出正式图标，建议统一为**圆角线性 + 蜜色描边**风格，尺寸至少覆盖 96×96（图标钮）与 140×140（弹窗头部）。
4. **必须保留的功能性表达 / 必须遵守的约束**：
   - 「置灰但仍可点 + 点击给提示」这套状态表达；
   - 排行榜「挑战本关」**按钮文案即原因**（解锁条件 / 素材不足）；
   - 棋盘上「独立块白描边 / 融合块金描边」的区分；
   - 碎片"缺素材退化为色块"的兜底态；
   - 倒计时 60s/10s 两档告警色；
   - 榜单"我的行"高亮；
   - **不提供任何暂停入口**（无暂停按钮、无暂停弹窗，见 §0 第 1 条）；
   - **玩法屏不出现底部页签栏**：能一键跳走就等于能暂停；页签栏只在非玩法屏常驻，重设计玩法屏时请为它留出「隐藏」的表达；
   - 退出 / 切后台相关文案一律按**"时间照走"**表述，不要写"已暂停"。
5. **安全边**：内容与可拖拽区不要贴屏幕边（左右 28 / 上下 12 屏幕 px 是系统手势区）。
6. **交付格式**：建议按"屏 × 状态"出稿，状态清单直接用 §6 的表逐行打勾，避免漏态。
