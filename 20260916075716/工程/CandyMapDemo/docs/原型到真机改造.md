# 萌宠拼拼乐 · 对局界面原型 → 微信小游戏真机改造

> 日期：2026-10-25。本文档整理从 `design/` 三个 HTML 原型到微信小游戏真机的全部改造信息。
> 分支：`pure-code/minigame`（纯代码微信小游戏，无引擎无编辑器）。

---

## 一、总体架构

```
design/prototype-a-candy.html    ← 原型 A「糖果嘉年华」（糖果传奇流派）
design/prototype-b-clean.html    ← 原型 B「果冻乐园」（Royal Match 流派）
design/prototype-c-journal.html  ← 原型 C「贴纸手账」（本作专属流派）
design/index.html                ← 三原型入口页

           ↓  移植到真机

assets/scripts/玩法/theme.ts         ← 三主题数据 + 全套文案 + 关卡绑定
assets/scripts/玩法/themeResult.ts  ← 主题化通关/失败弹窗
assets/scripts/玩法/themeExtras.ts  ← 连击词 / 棋盘操作提示 / 首次玩法指引
assets/scripts/玩法/GameBootstrap.ts ← HUD 排版（照抄原型 A）+ 主题接入
assets/scripts/玩法/BoardView.ts    ← 棋盘底板 + 融合环（主题配色）
assets/scripts/核心/progress.ts     ← 出厂 unlocked=4（2/3/4 关默认可玩）
```

**核心原则：只换皮，不动玩法**——引擎（PuzzleEngine）、碎片模型（pieces.ts）、融合判定（merge.ts）、关卡配置（config.ts）全部不动，主题只决定 Graphics 画出来的颜色/圆角/线宽/字体和文案。

## 二、三主题数据结构

### 文件：`assets/scripts/玩法/theme.ts`

```typescript
export type ThemeId = 'candy' | 'clean' | 'journal';

export interface GameTheme {
  id: ThemeId;
  name: string;               // 「糖果嘉年华」/「果冻乐园」/「贴纸手账」
  // ---- 视觉 ----
  bgTop/bgBottom: Color;      // 对局背景渐变
  hudStyle: 'bar' | 'pills';  // 整条横牌 vs 悬浮胶囊
  hudFillA/hudFillB: Color;   // HUD 填充色
  hudText/hudAccent: Color;   // 主文字 / 数值强调
  textShadow: boolean;        // 粗体白字（candy）
  fontFamily: string;         // SANS vs KAI（楷体）
  backFill/hintFill: Color;   // 按钮
  panelFillA/B, panelBorder: Color;  // 棋盘底板
  ringColor: Color; ringWidth: number; ringSketchy: boolean;  // 融合环
  // ---- 文案 ----
  copy: ThemeCopy;
}

export interface ThemeCopy {
  modeLabel: string;                    // 「简单模式」/「简单」
  boardHint: string;                    // 棋盘下方操作提示
  combo: string[];                      // 连击词（按连锁数升序）
  honor: [string, string, string];      // 荣誉头衔（3星/2星/1星）
  winScore/winStickers/winTotal: string;// 结算表标签
  newBest: string;                      // 「新纪录」
  nextLevel/backToMap: string;          // 按钮文案
  failTitle: string;                    // 失败标题
  failSub: (need: number) => string;    // 失败副标题（差多少分）
  reviveTitle/reviveSub/reviveAd/reviveBtn/giveUp: string;
  cardBg/cardBorder/honorColor/tallyBg: Color;   // 结算弹窗配色
  primaryFill/primaryEdge/secondaryFill: Color;  // 按钮配色
  honorFontSize: number;                // 荣誉头衔字号
}
```

### 关卡绑定

```typescript
export function themeForLevel(level: number): GameTheme {
  const idx = (Math.max(1, level) - 1) % 3;  // 0/1/2 循环
  return THEMES[ORDER[idx]!];
}
```

| 第 4 关 | candy（循环） |
| 第 5 关 | clean（循环） |
| ... | ... |

`GameBootstrap.beginLevel()` 调 `setThemeForLevel(level)`，进关即换皮。

## 九、图片切片

- 素材来自远程 `https://candy.aidertech.cn/mini-assets/pp/stickers/sticker_*.png`
- 每张贴纸 512×512，切为四象限（左上/右上/左下/右下各 256×256）
- 碎片 ID = 图ID × 4 + 位置（0=TL, 1=TR, 2=BL, 3=BR）
- 融合判定：同图 + 网格相邻 + 相对位置正确 → 连通分量满 4 ⟺ 正确 2×2 ⟺ 消除

## 十二、改主题/加主题的步骤

1. **加主题**：在 `theme.ts` 的 `ThemeId` 加新 ID，在 `THEMES` 加完整数据（含 `copy`），在 `ORDER` 数组加 ID。
2. **改文案**：只改对应主题的 `copy` 字段——不影响其他主题。
3. **改视觉**：只改颜色/字体/线宽字段——HUD / 棋盘 / 弹窗自动跟随。
4. **验证**：`node --import ./test/ts-resolve.mjs --test test/*.test.ts` + `node tools/build-minigame.ts` + 微信开发者工具重新编译。
