# 逐屏核对：Web 版界面 vs Cocos 端重建界面

> 目标：把「Web 版有什么」vs「Cocos 端有什么」一屏一屏地列清楚，回答用户的批评
> 「移植是移植整个游戏，你的测试游戏，没有和 web 一致，UI 所有的功能玩法全变样了」。
>
> **口径说明**：
> - **Web 版**（`工程/web/`，Vite + TS + DOM/CSS）是产品口径的原始定义，禁改。
> - **Cocos 版**（`工程/assets/scripts/`）是移植产物，目标微信小游戏。
> - Cocos 端界面是**按 Web 版截图/文案用 Graphics 重新画的**，不是逐元素对照移植，
>   因此凡是"用 Graphics 画的圆角矩形/色块"一律注明「重建，非逐像素还原」。
> - 判定三档：`完整` / `部分` / `缺失`。
> - **数值只写读到的，读不到就写"未读到"，不编。**
>
> 核对顺序：首页/主界面 → 地图选关页 → 对局 HUD → 结算 → 排行榜 → 图鉴 → 设置 → 教学/引导 → 弹窗体系 → 其他

### 1.6 修遗憾：点关卡珠进不了玩法（2026-10-31）→ 已修，数值验证通过

| # | 根因 | 证据 | 修法 |

- `layout()`：`availW = 1080-64 = 1016`、`availH = 1420-24 = 1396`；`cell = floor(min((availW - GAP*(cols-1))/cols, (availH - GAP*(rows-1))/rows))`。
  - 推算（4×3）：`(1016-24)/3 = 330`、`(1396-36)/4 = 340` → `cell = 330`，棋盘宽 `3*330+24 = 1014`。
- `BoardView.ts`：`GAP = 12`（与 Web 一致 ✅）；`edge: 0`（BoardView.ts:316 注释明写「Cocos 版没有白描边」）vs Web `EDGE = 2`。
- 融合外扩：`Math.round(cellSize*0.1)`（Web）vs 固定 `r = 12`（Cocos，BoardView.ts:155）。
- 选中 / 提示环：`strokeColor (255,214,92)` = `#FFD65C`，`lineWidth 6`。

### 承载方式（必须先搞对，否则 UI 再准也是错的）

Web 端教学的信息载体是「**语音 + 聚光灯气泡**」，不是把台词铺到屏幕上：

| 环节 | Web 端做法 | Cocos 端落地 |
|---|---|---|
| 开场（讲规则 / 拖手势） | `tutorialSay()` = 横幅 + speech | 横幅（speech 静默，见下） |
| 讲目标旗 / 倒计时 / 倒计时走完 | **聚光灯气泡 + speech**，不弹横幅 | 同（本轮修好：之前是横幅 + 气泡同一句显示两遍） |
| 讲整片 / 困难重玩 | `tutorialSay()` = 横幅 | 横幅 |

`Speech` 在 Cocos 端是**静默实现**（小游戏无 TTS），这不是缺陷，但正因如此

| 元素 | Web CSS | Cocos 实测 | 结论 |
|---|---|---|---|
| 横幅背板 | `padding 22/44`，胶囊 `radius 999` | 718×101（=15 字×42 + 88 padding / 57 + 44） | 一致 |
| 横幅文字 | #ffe9b8 / 42px / 800 | `fontSize 42`，色 `(255,233,184)` | 一致（早期移植是米白底深棕字，颜色反了） |
| 横幅底色 | rgba(40,22,0,.82) | `(40,22,0,209)` | 一致 |
| 聚光灯光泡 | 宽 ≤360，`padding 22/26`，`radius 22`，5px rgba(190,130,50,.8) 描边 | 底板 360×166，内含文字 308×122 | 包得住 |
| 气泡文字 | #6d3f00 / 40px / 800 / center | `fontSize 40`，色 `(109,63,0)` | 一致 |
| 继续圆钮 | 76×76 圆，rgba(255,200,90,.95)，字 #7a4100 44px | 76×76，色 `(122,65,0)` | 一致 |

### 本轮同时修掉的运行时缺陷

- **聚光灯压根不显示**：`SpotlightLayer.show()` 只改了透明度，没把整层重新 `active = true`
  （而 `hide()` 会置 false）。表现就是"只有那条孤零零的横幅在念台词"。
- 继续圆钮被 Label 的 `overflow: NONE` 挤成 37×96（Label 会改写节点尺寸），改为 CLAMP 后回到 76×76。
- 气泡高度取「渲染后实测值」与「按字符宽估算行数」的较大者，避免底板比文字矮一截。
