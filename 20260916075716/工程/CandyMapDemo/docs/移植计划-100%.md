## 0. 铁律

1. **`web/` 是唯一事实源**。任何不一致 = 缺陷，不许用「技术栈不同」解释视觉/交互差异。
2. **不许照截图脑补**，也不许照记忆写：读 Web 源码（`web/ui/*.ts`）+ `web/ui.css` 逐元素对照。
3. **切图优先、程序绘制兜底**：`web/art/` 里有的图，一律拿过来用，不许用 Graphics 另画一个「长得差不多」的。
   程序绘制只留给 **Web 端也没有切图** 的东西（纯 CSS 渐变、border、emoji、文本）。
4. 禁改 `web/`；禁改策划配置 `核心/config.ts`（`GRID_BY_LEVEL` / `STAR_LINES` / 图池）。
5. 不 `git push`；提交用 `git add -- <具体文件>`，不用 `git add -A`。

## 1. 坐标与命名口径

| 项 | 口径 |
|---|---|
| 画布 | **1080 × 1920 逻辑坐标**（`uiPaint.STAGE_W/STAGE_H`） |
| 原点 | 左上，`y` 向下（与 `ui-dump.mjs` 一致） |
| 节点坐标 | Cocos 是**中心锚点 + y 向上**，写布局时按 uiPaint 既有 helper 换算，不混用两套 |
| 切图落点 | `assets/resources/ui/<页面目录>/<名字>.png`（地图底图走 `resources/map/`，关卡珠走 `map/node/`） |
| 资源解析 | `uiPaint.mkSprite(parent, 'leaderboard/row', w, h)` → `resolveAsset('ui', res, 'png')` |
| 字体 | HarmonyOS Sans SC（免费商用），禁引付费字体 |

**三种铺法必须照 Web 的 CSS 来**（不许想当然）：

| Web CSS | Cocos 写法 | 例子 |
|---|---|---|
| `background-size: 100% 100%` | `mkSprite(node, res, 盒宽, 盒高)` 直接铺满 | `row.png` / `header.png` / `frame.png` / `podium-*` |
| `object-fit: contain` 或只给宽/高之一 | `fitContain(原图w, 原图h, 盒w, 盒h)` 算实际尺寸 | `medal-*`（131×154 进 84×94 → 80×94）、`cup-*`（只给 width，高按原图比例） |
| `background-size: cover` | 按盒裁切（当前头像 84×84 直接给定尺寸） | `avatar-*` 84×84 |

## 4. 切图接线规范（照抄时的手边速查）

```ts
// 铺满（Web: background-size: 100% 100%）
mkSprite(node, 'leaderboard/row', LIST_W, ROW_H);

// contain（Web: object-fit: contain / 只给一边）
const [w, h] = fitContain(原图w, 原图h, 盒w, 盒h);
mkSprite(node, `leaderboard/medal-${rank}`, w, h);

// 换状态图（Web: 换 background-image）
setSprite(btn.sprite, 'leaderboard/tab-on');   // 失败自动回落程序绘制，不开天窗

// 切图必须「最后加」：盖在程序绘制的兜底层之上，加载失败就只剩兜底，不会开天窗
```

- 新图先 `Copy-Item web/art/<目录>/<图>.png assets/resources/ui/<目录>/`，Creator 会自动生成 `.meta`（要一并提交）。
- 路径一律 `ui/<目录>/<名字>`（不含扩展名），底图/关卡珠例外：`map/w1_town`、`map/node/node-todo`。

## 5. 单页作业 SOP（**每页都按这 7 步走**）

1. **读本文档** §3 找到该屏，记下 Web 源码 / CSS 行号 / 切图清单 / Cocos 落点。
2. **读 Web 源码**：`web/ui/<屏>.ts` + `web/ui.css` 对应段，列出**全部可见元素**（位置 / 尺寸 / 颜色 / 文案 / 图标 / 数值）+ **全部交互**（点击 / 滑动 / 条件显隐 / 动画）。文案以 `玩法/text.ts` 对齐 Web 原文。
3. **采 Web 基线**：`ui-dump.mjs --probe web-<屏>` 出 JSON + 截图（缺探针就在 :757-771 加）。
4. **读 Cocos 现状**：对应脚本现在画成什么样，列出「已接切图 / 仍程序绘制」。
5. **照抄**：先补切图（§4），再改几何。⚠️ 若该屏是「照截图随手画的」，**直接重画，不要打补丁**。
6. **采 Cocos + diff**：`ui-diff.mjs` / `check-*.mjs`，把 Δ 压到 0（位置 ≤2px、字号 ≤1px、文案逐字相等、无单侧缺失）。新屏要在 `ui-diff.mjs` 的 MAP 里补节点映射。
7. **跑三道关 + 记录**：
   - 单测 `node --experimental-strip-types --import ./test/ts-resolve.mjs --test "test/*.test.ts"`（基线 **245/245**）
   - 可移植性守卫 `node tools/check-portability.mjs`（基线 **56 文件**）
   - 浏览器内实例化零异常：`http://127.0.0.1:5181/preview/game.html`（必须硬刷新 Ctrl+Shift+R）
   - 结论追加写 `docs/核对-界面.md`，并在本文档 §3 把状态改成 ✅
