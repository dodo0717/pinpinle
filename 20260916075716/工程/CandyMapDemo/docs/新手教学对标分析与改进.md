# 新手教学对标分析与改进（对标热门休闲手游）

> 日期：2026-10-26 · 版本：v1
> 目的：把我们的「序章教学」放到**热门休闲手游**的尺子上量一遍，找出差在哪，输出可落地的改进（并入 `docs/新手教学（序章）策划案.md` 的 v3.1）
> 对标对象：Candy Crush Saga（消除类标杆）/ Royal Match（近年增长最快）/ 开心消消乐（国内同类）/ 羊了个羊·抓大鹅类（极简爆款）/ Block Blast（极简方块消除）/ Merge Mansion（渐进式机制引入）

---

## 0. 先说结论（三句话）

1. **v3 的核心做法已经对齐标杆**——「强制只准拖那一块 + 手指滑动动画 + 零文字 + 先做后讲」正是 Candy Crush / Royal Match 的通行做法，这条路**没走错**。
2. **真正的差距不在"怎么教"，而在 FTUE 的整体节奏**：玩家要**点 4 次**才摸到第一块碎片（行业是打开即玩）、教学**没有奖励闭环**、**后面的新机制没人教**。
3. 三个 P0 改进：**① 新档首次启动直接进序章（不再先弹抽屉）② 每拼一组给一次强反馈（3 组才有节奏）③ 完成教学给奖励（体力 +5）**。

## 1. 对标尺子（12 项）

| # | 维度 | 行业标杆做法（依据） |
|---|---|---|
| 1 | **到达首次操作的时间** | **30 秒内**必须上手（onboarding 通则）；"dead air（长介绍屏、菜单跳转）是留存杀手" |
| 2 | 教学是否独立成关 | **融入第一个真实关卡**：Candy Crush **Level 1 本身就是 tutorial level**（教 swipe，6 步 / 300 分） |
| 3 | 是否强制唯一操作 | **是**：第一步只有一个可行解，其余输入被锁 |
| 4 | 手指 / 动画演示 | **是**：循环播放"按住→滑→松手"，玩家一按就停 |
| 5 | 文字量 | **几乎为零**：靠高亮 + 动画 + 图标，不靠读 |
| 6 | 教学关能否失败 | **不能**：Candy Crush L1 难度 **0%**、"can be completed in any way" |
| 7 | 教学时长 / 完成条件 | **极短**：一步到几步就"过关"，先给成就感 |
| 8 | 首次成功的反馈强度 | **爆米花式**：爆炸 + 粒子 + 音效 + 分数飞入 |
| 9 | 奖励闭环 | **有**：通关给星星 / 宝箱 / 解锁下一个内容 |
| 10 | 后续新机制怎么教 | **渐进式**：每引入一个新机制，复用同一套"强制一步 + 动画"教一次（一次只教一件事，工作记忆只有 4 格） |
| 11 | 可跳过 / 可回看 | **两者都要**：教学内可跳过，设置里有"How to play"常驻回看 |
| 12 | 卡住保护 | **有**：几秒不动就重播演示；教学关不会真卡住 |

> 「现状」= v1 已实现 + v3 方案（v3 尚未开工）

|---|---|---|---|---|

| 5 | 文字量 | 接近零 | **零文字**（序章内无横幅/气泡） | ✅ 已对齐 |
| 6 | 教学关能否失败 | 不能 | **不能**（全程冻结、无失败结算） | ✅ 已对齐 |

| 8 | 首次成功反馈 | 爆炸级 | 现有消除动画（融合→消除→下压→补位） | 🟡 P2：首次可加一次"专属大反馈" |
| 9 | 奖励闭环 | 有 | **完全没有**——完成弹窗只有三行说明 | 🔴 **P0** |
| 10 | 后续机制教学 | 复用同一套 | **无**：融合大块、掉落补位、困难模式规则、道具…… 正式关里首次出现时没人教 | 🔴 **P1** |
| 11 | 可跳过 / 可回看 | 都要 | 序章内「跳过」✅；设置页 + 首页胶囊可回看 ✅ | ✅ 已对齐 |
| 12 | 卡住保护 | 有 | 有（3 秒重播、30 秒降级解锁） | ✅ 已对齐 |

## 3. 差距清单（按影响排序）

### 🔴 P0-1｜到第一次拖动要走 4 步，还先读一屏字

- **行业**：打开 → 直接进第 1 关 → 手指已经在演示了。
- **我们**：打开 → 首页 → 抽屉自动展开（一屏图文） → 点「开始教学」 → 才进序章。
- **为什么这是第一位的**：首次会话的前 30 秒决定留存（行业 Day1 留存 25~35%）；"先读说明书再做"正是"teach before the player has a reason to care"的典型错误——玩家还没碰过任何东西，没有上下文，也没有耐心读。
- **改进（v3.1-A）**：**新档首次启动直接进序章**，不再先弹抽屉。
  - 判据：`!meta.tutorial.seen && !normalCleared && 困难通关 < 10` → `ready` 后直接 `startTutorial('normal')`；
  - 抽屉**不再自动展开**，退回到它的本职：**回看 / 重玩**入口（首页胶囊 + 设置页）；
  - 序章右上角「跳过教学」→ 跳过后回首页——**没有剥夺"先逛一圈"**，反而少了一道门。

### 🔴 P0-2｜3 组的路太长，中途没有"我进步了"的信号

- **行业**：教学关目标极低（Candy Crush L1：6 步 / 300 分 / 0% 难度），先给一次"我赢了"的爽感，再上难度。
- **我们**：要拼满 **3 组**才弹完成，中途（v3 零文字后）**没有任何进度信号**——玩家不知道还要多久。
- **改进（v3.1-B）**：保留"3 组完成"（你的决策），但**每组都给一次强反馈**（仍然零文字）：
  1. 拼成 1 组 → 旗子 `#hud-goal` 数字 **3 跳 2** + 旗子自己**抖一下 + 金光**；
  2. 得分区翻牌 +1（已有）；
  3. 棋盘上方**进度点**：3 颗小星点亮第 1 颗（纯图形，零文字）—— 玩家一眼看到"还差 2 颗"；
  4. 拼到第 3 组 → 三颗星全亮 + 完成弹窗。
- **备选**（要你定）：把 3 组缩到 **2 组**（更贴近标杆的"极短"）。

### 🔴 P0-3｜教学结束不给任何东西

- **行业**：通关给星星 / 宝箱 / 解锁，构成"学会 → 有回报"的闭环。
- **我们**：完成弹窗只有三行说明，点「开始第 1 关」就走了——**学习成本付了，回报为零**。
- 改进（v3.1-C）**已实现（2026-10-26，形式有调整）**：
  - ✅ **第 1 关免 1 颗体力**（`meta.tutorial.freeLevel`）—— **主奖励**；
  - ✅ **体力 +5** 作为余量补充（不满时生效）。
  - ⚠️ 原方案「只送体力 +5」实测发现是**假奖励**：序章一颗不扣，新玩家体力本来就是满的，
    `+5` 会被 `STAMINA_MAX` 吃掉。改成"第 1 关免单"后，任何玩家都实打实省一颗。
  - ⚠️ 仍然**不送星、不送图鉴贴纸**：那两个会污染排行榜与图鉴（每 10 星一张）规则。

### 🟡 P1-1｜后面的新机制没人教

- **行业**：每引入一个新机制（特殊糖、障碍、道具），都用同一套"强制一步 + 动画"教一次，**一次只教一件**。
- **我们**：只有序章教"拖动"；正式关里**首次遇到融合大块、掉落补位、困难模式"挪一格"**时，玩家自己悟。
- **改进（v3.1-D）**：把 v3 的教学机制**抽象成可复用组件**（这是 ROI 最高的一步）：
  ```
  forceStep({ targetIndex, gapIndex, spotlight?, onDone })
    ├─ 输入锁：只有 targetIndex 能拖
    ├─ 落点锁：只能落 gapIndex
    ├─ 手指滑动动画（循环 / 一按就停 / 停手 3 秒重播）
    └─ 可选聚光灯：挖出 #hud-goal / #hud-timer / 任意 .cell
  ```
  后续复用点（按优先级）：① 困难模式首次进入 → 教"挪一格" ② 首次出现 ≥3 块融合大块 → 教"整片拖拉" ③ 首次补位 → 教"上面会掉下来"。

### 🟡 P1-2｜教学关与正式关之间有个"坎"

- **行业**：第 1 关就是教学，学完即玩，**没有"现在才真正开始"的割裂感**。
- **我们**：序章（level 0）→ 完成弹窗 → 点「开始第 1 关」→ 第 1 关。中间多一次"重新出发"的心理成本。
- **改进（保留独立序章的前提下）**：
  - 完成弹窗主按钮文案改成「**继续第 1 关**」（不是"开始"，暗示是接着走）；
  - 点主按钮 → **直接进第 1 关**（已实现），中间**不再回首页**；
  - 序章的棋盘 / HUD 与正式关**完全一致**（已经是同一套），视觉上无缝。

### 🟢 P2｜首次消除的反馈可以更"爆"

- **行业**：第一次消除给超规格反馈（爆炸 + 糖屑 + 镜头轻震 + 音效加强）—— 这是"爽感锚点"，后面会一直回味。
- **改进**：序章**首次消除**时给一次专属大反馈：金光炸开 + 粒子 + `audio.play('win')` 轻版 + 棋盘轻微缩放脉冲（0.25s）。只在第一次触发，之后回归常规。

### 🟢 P2｜没有教学完成率数据

- **行业**：FTUE 每步埋点（开始 / 每步完成 / 跳过 / 完成）。
- **改进（低成本）**：`meta.tutorial` 里加 `stepReached`（走到第几步）与 `skipped`（是否跳过），存 localStorage，开发期可在 devbar 看。

## 4. 改进后的流程（v3.1，零文字不变）

```
打开游戏（新档）
   │
   ├─ 直接进【序章】                    ← P0-1：不再先弹抽屉
   │    ├─ 盘面：3 缺 1（3 块成 L + 缺块紧邻）
   │    ├─ 强制：只有那块能拖、只能落缺口
   │    ├─ 动画：手指滑动 1.6s 循环（一按就停，停手 3 秒重播）
   │    └─ 零文字：全程无一个字
   │
   ├─ 拖对了 → 4 块拼合 → 消除  ★首次消除给大反馈（P2）
   │    └─ 反馈：旗子数字 3→2 抖动 + 进度点第 1 颗星亮（P0-2）
   │
   ├─ 旗子聚光灯（数字跳变，无文字）→ 倒计时聚光灯（真走 3 秒 → 冻回）
   │
   ├─ 第 2、3 组：整片拖拉教学（同一套 forceStep）
   │    └─ 每组：进度点点亮 + 旗子数字跳变
   │
   └─ 3 组达成 → 完成弹窗
        ├─ 三行结算说明（倒计时 / 排行榜 / 图鉴）
        ├─ ★奖励条：体力 +5（心飞向 HUD）      ← P0-3
        └─ 主按钮「继续第 1 关」→ 直接进第 1 关  ← P1-2

老玩家回看：首页「教学」胶囊 / 设置页 → 抽屉（重玩两个序章 + 怎么玩图解）
```

## 5. 需要你拍板（4 项）

| # | 问题 | 我的建议 | 依据 |
|---|---|---|---|
| 1 | **新档是否直接进序章**（不再先弹抽屉） | **是** —— 这是 12 项里最大的差距 | 行业"打开即玩 / 先做后讲"；dead air 是留存杀手 |
| 2 | 教学完成奖励 | **体力 +5**（不送星、不送贴纸） | 闭环必要；星/贴纸会污染排行榜与图鉴规则 |
| 3 | 完成条件：3 组还是 2 组 | **保留 3 组**，但补上"每组进度点 + 旗子跳变" | 你原定的 3 星目标；补节奏后 3 组不长 |
| 4 | 后续机制教学（困难模式 / 融合大块 / 补位） | **做**，把强制步进抽成可复用组件 | 行业"一次只教一件事"；这是 ROI 最高的一次投入 |
