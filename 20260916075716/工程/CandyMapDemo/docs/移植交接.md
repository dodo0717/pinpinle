## 6. 红线与坑

- **可移植性红线**：`assets/scripts` 下算法/界面层不能出现平台依赖。全局 `setTimeout` 可用（不加 `window.` 前缀）。
- **文案集中在 `玩法/text.ts`**，界面组件里不要硬编码中文。
- **不要改策划配置**：`核心/config.ts` 的 `GRID_BY_LEVEL`、星级线、图池是策划配好的。
- **不要改 `web/`**（参照源）。
- **默认必须全本地**：`平台/assetSource.ts` 的 `cdnBase` 为空时所有资源走 `resources`，
  本地渲染路径与改造前逐字一致。改资源加载时**这条优先于"支持 CDN"**——宁可 CDN 留 TODO，也不能改坏本地渲染。
- **CDN 分支未实机验证**：`assetManager.loadRemote` 只按文档写。真机若对不上，只改 `loadRemoteSpriteFrame()` 一个函数。
- **素材压缩产物**在 `minigame/assets/`（已被 gitignore，**不改动原素材**）：
  贴纸 46.83→10.20 MB、底图 13.37→7.60 MB、UI 2.48→0.17 MB，小游戏三组合计 **17.97 MB**（总包 20 MB 内，需拆 5 个分包）。
- **字体 16 MB**：子集化字符表 1218 字已生成（`tools/font-chars.txt`，UTF-8 无 BOM），
  **pyftsubset 未实测**（本机 fonttools 未确认）；跑不通就改远程加载。
- **提交用 `git add -- <具体文件>`**，不要 `git add -A`（工作区有压缩产物与临时目录）。**不 push**（用户统一推送）。
- 本机删除操作可能被安全策略拒绝（trash 失败），删不掉别硬删。
- PowerShell 里写文件必须显式指定 `-Encoding`，否则会被安全规则拦截；命令文本里出现
  `Set-Content` / `Out-File` 字样也可能被误拦。
