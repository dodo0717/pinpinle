# 选关地图底图生成

**画面具体内容由用户线稿/主题决定**。本 SKILL 把规范拆成两层：**铁律（固定骨架，所有地图通用，不随主题改变）** 与 **画面内容（可替换变量，换地图只改这一层）**。生成时 = 固定铁律 + 当次画面内容。

提示词以**正面描述为主**，避免堆砌负面词，否则 AI 会机械执行、构图生硬。

## 一、6 条铁律（固定，所有地图通用）

1. **游戏平铺 · 2.5D 斜俯视平铺画面，无透视**：整体平铺、视角统一，无一点透视、无地平线。
2. **尺寸 / 裁剪**：图片按 **4K（2160×3840）生成 → 居中裁剪 1080×3840**（等同手机 2 屏）。不分段拼接。
3. **风格：2.5D 软卡通场景，毛绒潮玩动物角色**：温馨治愈、立体软卡通渲染质感；角色为潮玩拟人动物（毛绒质感）。
4. **上下各约 10% 比例为简洁装饰（预留 UI）**：但装饰带**与原图保持一个整体、不独立成画**，不单独生成一片装饰画面。
5. **中路留白 = 关卡节点层**：中间微蜿蜒小路干净留白，**禁止在道路上放任何东西**（角色、建筑、树木、摊位、路灯、遮挡物均不可）。
6. **比例**：**建筑入画约 50%**、**角色约建筑 1/2-1/3 高**，角色大小与**主流手机游戏规格保持一致**。

## 二、画面内容（可替换变量，换地图只改这一层）

1. **故事感**：角色之间互动叙事，有生活气息。
2. **画面中间约 30% 是微蜿蜒的小路**（干净留白，参照铁律 5）。
3. **画面两侧是角色互动 + 树木、小屋、钟楼、商铺、喷泉、风车等**（按当次地图主题/线稿取舍）；**内容禁止同质化**——禁止同一建筑模样、同一角色模样。不画横跨的桥；如必须加桥，桥竖放（纵向、沿道路方向）。
4. **建筑造型各异、角色动物各异、比例协调**（参照铁律 6），符合手机游戏建筑与角色比例。

### 换地图操作
- 铁律一层**不改**；只把「画面内容」里的**两侧元素清单 + 三段分区**替换成新主题（如果园/花园/沙滩/雪地）即可。
- 具体到某一主题时，画面内容用线稿/用户措辞逐段列出两侧元素与角色互动。

- [ ] 游戏平铺 · 2.5D 斜俯视、无透视、无地平线
- [ ] 2.5D 软卡通场景、毛绒潮玩动物角色
- [ ] 中间约 30% 微蜿蜒小路干净留白（关卡节点层），路上空无一物
- [ ] 上下各约 10% 简洁装饰（预留 UI），且与原图同一整体、不独立成画
- [ ] 建筑入画约 50%、角色约建筑 1/2-1/3 高、符合手机游戏比例
- [ ] 建筑造型各异、角色动物各异、无同质化
